Answer: E

Two sequences are interleaved: the 1st, 3rd, 5th… numbers increase by 4, and the 2nd, 4th, 6th… decrease by 3. So the next number is 16.

How to approach this type

Number series questions show a sequence and ask for the next term. Almost every one is built from a small set of rules, so a systematic checklist beats inspiration.

Step 1: look at the differences

Write the gap between each pair of neighbouring numbers. If the gaps are all equal, it is an arithmetic sequence: add the gap again. If the gaps themselves change by a constant amount (2, 4, 6, 8…), the sequence is quadratic: extend the gaps first, then add.

Step 2: try ratios

If the numbers grow quickly, divide each term by the one before. A constant ratio (×2, ×3) means a geometric sequence. If the ratio is almost constant, check “multiply then add”: 3, 7, 15, 31 is ×2 + 1.
