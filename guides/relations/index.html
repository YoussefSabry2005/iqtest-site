How to solve number relationship (function) questions

These questions show pairs like 3 → 10 and 5 → 26 and ask what a new number maps to. The task is to find the single rule that produces every right-hand number.

Start with simple operations

Compare each output with its input: is it roughly double? roughly the square? 3 → 10 and 5 → 26 suggest squaring plus one (9 + 1, 25 + 1).

Test the rule on every pair

A rule that works for one pair is a guess; one that works for all pairs is the answer. Check each pair before choosing.

Common families

Squares (x²), squares plus/minus a constant, x × (x + 1), doubling or tripling plus/minus a constant, and cubes cover most questions.
