How to solve matrix reasoning puzzles

Matrix puzzles show a 3×3 grid of tiles with one missing. Each feature of the tiles (shape, number of shapes, fill) follows its own rule across the rows.

Separate the features

Do not look at whole tiles. Ask three separate questions: what happens to the shape? to the number of shapes? to the fill?

The three common rules

A feature can stay constant across a row, progress (1, 2, 3 shapes), or be distributed, meaning each row contains each value exactly once, like a Sudoku row.

Solve the bottom row last

Work out each rule from the two complete rows, then apply it to the bottom row to predict the missing tile feature by feature.

Eliminate options

Cross out options that break even one feature rule. Usually only one tile survives.

Common mistakes

  • Looking at whole tiles instead of one feature at a time.
  • Assuming every feature changes; often one stays constant along each row.
  • Ignoring columns: occasionally the clearer rule runs down the columns.
  • Choosing the first option that looks right without checking the other features.

A simple practice plan

For each practice grid, write three short notes: shape rule, number rule, fill rule. Only then look at the options. This habit is slower at first and much faster within a few sessions.
